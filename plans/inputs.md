# Inputs to add to the repository

> Part of [PLAN.md](../PLAN.md).

Put raw inputs in `import/` (add `import/private/` to `.gitignore` for anything not to be published).

| File | Content | Needed for |
| --- | --- | --- |
| `import/handbook-claims.md` | Google Doc export (File → Download → Markdown), unedited | Phase 2 |
| `import/lectures.csv` | One row per lecture: title, speaker, affiliation, date, video/recording URL, transcript file name, consent to be named (yes/no) | Phase 2 |
| `import/private/transcripts/raw/` | Raw MS Teams transcripts (.docx or, preferably, .vtt) with timestamps and speakers (private; used for locators only) | Phase 2–3 |
| `import/questionnaires.csv` | Student questionnaire answers (anonymise or confirm consent) | Phase 2 |
| `import/posters/` | All posters as PDF + PNG/JPG, file name = poster title | Phase 4 |
| `import/posters.csv` | poster title, student(s) = case-study note name, group, strategy number | Phase 4 |
| `import/feedback-summary.md` | Exhibition / Rethinking.Cities / review-form feedback summary (optional, for About page) | Phase 5 |
| `import/partners/` | Logos (SVG/PNG) and approved acknowledgement text for Ramboll Foundation and partners | Phase 5 |
| `import/metadata.yml` | Authors and ORCIDs for Zenodo, licence confirmation, D3 paper reference and status, ULI talk date | Phase 5, 7 |
