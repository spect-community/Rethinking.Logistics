## Context

A student whose project converts abandoned buildings into data centres asked Paul Astle (Ramboll) whether renovation or new build is better for carbon. Astle answers that because data centres are dominated by operational carbon, reusing a building should not compromise their efficiency.

## From the transcript

> And because data centres are dominated by operational carbon, what we wouldn't want to do is to compromise the operational efficiency of a data centre by reusing a building, because if we did that, on a whole life cycle [it's] probably worse. […] But if the data centre is 10% less efficient because of some problem to do with the existing building, over that life it may well have been better to […] I wouldn't say demolish the building and [rebuild] it. I'd say put the data centre somewhere else and have that building used for a different purpose, because reusing existing buildings is good, but it's important that we reuse the buildings for the right next life and if we try and force a different purpose onto an existing building that was never envisaged for that, we can create some quite strange outcomes.
